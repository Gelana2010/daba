GELANA ADUGNA — RESEARCH PROFILE WEBSITE

FILES
- index.html: website content and structure
- styles.css: visual design and responsive layout
- assets/: reserved for images or other local assets

UPDATE YOUR EXISTING GITHUB PAGES WEBSITE
1. Open https://github.com/gelana2010/gelana2010.github.io
2. Open index.html, choose Edit (pencil), and replace its contents with the updated index.html from this package. Alternatively, use Add file > Upload files to upload the updated index.html and styles.css together, replacing the existing versions.
3. Confirm that both index.html and styles.css are in the repository root, at the same level.
4. Make sure your CV PDF is in the same root folder and named exactly:
   Gelana_Adugna_CV.pdf
5. Commit the changes. GitHub Pages should publish the changes automatically.
6. Visit https://gelana2010.github.io/ and refresh after a few minutes.

CONTENT NOTES
- Publication titles and ResearchGate links supplied by the researcher are included.
- Contact/social links in the contact section remain general placeholders. Replace them with your actual professional profile URLs and email address before sharing the site widely.
- The CV links expect Gelana_Adugna_CV.pdf in the repository root.
- Check publication metadata, author order, and institutional wording for accuracy before public use.

The site uses semantic HTML, responsive CSS, and a small script for the mobile menu and current year. Google Fonts are optional; system sans-serif fonts are used as fallbacks.
